# **App Name**: MindMeld Chatbot

## Core Features:

- Intuitive Chat Interface: A clean, responsive UI where users can type messages and view real-time AI responses and conversation history.
- Intelligent Response Engine: Utilize an external AI API as a tool to process natural language queries and generate relevant, context-aware responses to user inputs.
- Firebase Conversation Storage: Securely store all user messages and AI responses in a Firestore database, ensuring persistent conversation history.
- Real-Time Message Display: Leverage Firebase services to push new messages and AI responses to the user interface instantly, providing a seamless chat experience.
- User Session Management: Track individual user sessions to maintain continuity of conversations and provide personalized interactions throughout a chat session.

## Style Guidelines:

- Primary color: A vibrant yet calming blue (#1B8FEF), chosen to evoke intelligence and clarity, contrasting well with a light background.
- Background color: A nearly-white shade with a very subtle blue tint (#F5F9FB), enhancing readability and providing an airy, modern feel.
- Accent color: A soft, clear cyan (#5ECFC8), analogous to the primary color, used for subtle highlights and interactive elements without being overpowering or conflicting.
- Headline and body font: 'Inter' (sans-serif) for its modern, highly readable, and objective appearance, suitable for a professional AI-driven application.
- Use a set of modern, minimalist line icons that clearly communicate common chat actions (e.g., send, clear chat, settings), ensuring a clean visual experience.
- A classic chat layout with messages appearing chronologically, a fixed input field at the bottom, and a clean, responsive design for optimal viewing across devices.
- Implement subtle, smooth animations for incoming messages and UI interactions, such as a fade-in effect for new chat bubbles and a gentle typing indicator to show AI processing.
